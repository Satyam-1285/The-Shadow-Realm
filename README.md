# CLI Shadow Realm Adventure

A lightweight, text-based RPG built in Python. This project demonstrates the use of dictionaries to manage game states and navigation logic.

## How to Play
1. Ensure you have Python installed.
2. Run the game: `python adventure.py`
3. Use commands like `Go North` or `Get Sword` to navigate and survive!

## Features
- Dynamic room navigation.
- Inventory system.
